APP_FORGE Hammer

A preview of what's coming in the next generation of APP_FORGE. The current stable release remains v2.1 — this page only tracks progress toward v2.3.

This is not a release. Nothing here is downloadable yet, and features may change before Hammer ships. For the current, stable version, see the main APP_FORGE page.
What's Coming

Landing in Hammer v2.3

📁
Configurable Resource Folders

Apps declare a shared "_GLOBAL" resource folder — license files, transforms, shared config — independent of version, opt-in per app.

Per-App Opt-InVersion-Independent
⚙️
Native AOT Engine

The core engine compiles to a single native executable — no .NET runtime install required, faster startup, smaller footprint.

Native AOTSingle Binary
📡
Live Log Streaming

Runs started without an interactive session now write their log in real time — tail it like any other live log, no more waiting until completion.

Real-TimeNo Console Needed
📦
Automatic Bundle Management

One permanent job per application, pointing at a bundle that always carries the current version — old test jobs clean up automatically.

BundlesSelf-Cleaning
🔍
Expanded Version Sources

Beyond GitHub & direct downloads: vendor JSON APIs, HTTP redirect-based detection, and HTML page scraping for vendors with no clean API.

VersionApiVersionRedirectVersionHtml
🧩
PSADT / BDS Integration

Deep integration with PowerShell App Deployment Toolkit installs, including automatic detection-rule handling and production promotion.

PSADTAuto-Promote

Machine-Readable Status

This preview also publishes a stable manifest for internal tooling to check against — not a live update API yet, just a fixed place to look.
