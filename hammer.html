v2.3 · 🔨 HAMMER · BETA · BUILD 91

Packages that build, test and release themselves.Pakete, die sich selbst bauen, testen und freigeben.

Hammer fetches new versions from the vendor, places them in the DIP, creates the application and jobs in the baramundi Management Suite, installs and uninstalls on the test client, lets the inventory confirm — and only then releases. Every step is in the log. This page shows it. Hammer is a service provider in your baramundi, not its master: what admins do in the console counts, and Hammer only changes its own objects.Hammer holt neue Versionen beim Hersteller, legt sie im DIP ab, erzeugt Anwendung und Jobs in der baramundi Management Suite, installiert und deinstalliert auf dem Testclient, lässt die Inventur bestätigen — und gibt erst dann frei. Jeder Schritt steht im Log. Diese Seite zeigt ihn. Hammer ist Dienstleister in Ihrer baramundi-Umgebung, nicht ihr Meister: Was Admins in der Konsole tun, gilt, und Hammer ändert nur seine eigenen Objekte.

Build 91 released 11 Nov 2026 · beta run followsveröffentlicht 11.11.2026 · Lauf in der Beta folgt

New

  • Glossary of placeholders and PSADT variables: a register of its own in the package editor and a panel in Reforge. For every placeholder it shows the meaning, where it is valid and a preview with the values of the open application; a click copies the name.
  • Package editor with registers instead of one long form. Messages are listed on top and lead to the field with a click.
  • Session duration of the web interface can be set per role (5–480 minutes). Two minutes before the end a warning with "Extend session" appears.
  • Release for production per version in the readiness overview when the automatic check of the uninstallation is switched off.
  • A change of the baramundi version is detected. The first cycle after it takes a new comparison baseline instead of reporting differences as changes.
  • Check rule for PSADT names: a warning appears when the application name of a package definition does not fit the application or names another one.

Improved

  • Changes an administrator makes on purpose in the baramundi console count as facts. A hold only happens for unclear values.
  • The test status of a version only moves forward; a test restarted on purpose is recorded as such.
  • Stuck tests are reported with their reason and can be restarted.
  • The plan for differing options of productive versions needs a single approval.
  • When a definition is created from an existing package, fields that still carry the template's name are marked and a replacement is offered.
  • When a session ends, input is kept and can be saved after signing in again.
  • More texts of the interface are translated into German and Spanish.

Fixed

  • After switching the application the editor still showed notes of the application opened before.
  • An outdated mark "local uninstaller" stayed after the installer type was changed.
  • Selection lists without an own value could be taken over as a value.
  • Deploy scripts counted as changed when only their header line differed.
  • Folders the retention rule had deleted itself were also reported as "removed from outside".
  • An uninstall line made of switches only was reported as an error although the local uninstaller had been detected.

Security

  • The session duration can be limited per role; every change is recorded in the log.
  • Release for production without a checked uninstallation only with an explicit approval per version.

Known limitations

  • The change of the baramundi version is only detected when this build ran at least one cycle before the change.
  • The preview in the glossary uses the last known version of an application; when none is known it shows a marked example.
  • For the list of programs to close, the check rule for PSADT names only warns when the list names nothing but another managed application.

Update notes

  • Install this build and let it run at least one cycle before changing the baramundi version.
  • Existing settings stay valid; the previous session duration applies to all roles until a value per role is set.
  • Existing package definitions and their placeholders are resolved unchanged.

Compatibility

  • baramundi Management Suite: operated with 2026 R1 (beta environment); findings from a test environment with 2026 R2 are taken into account. bConnect 1.1 and 2.0.
  • PSAppDeployToolkit 4.1.8 with template 4.10 (APP_FORGE PSADT Edition).

RequirementsVoraussetzungen

  • baramundi Management Suite with bConnect v1.1; inventory and uninstall verification additionally need bConnect v2.0 (from bMS 2025 R2), bundles bMS 2026 R1 — without bundles Hammer moves the test jobs into production as before. Operated with bMS 2026 R1 in the beta environment; prepared for 2026 R2, the first complete cycle there is still to come.baramundi Management Suite mit bConnect v1.1; für Inventur und Deinstallations-Verifikation zusätzlich bConnect v2.0 (ab bMS 2025 R2), für Bundles bMS 2026 R1 — ohne Bundles verschiebt Hammer die Testjobs wie bisher in die Produktion. Betrieben mit bMS 2026 R1 in der Beta-Umgebung; für 2026 R2 vorbereitet, der erste vollständige Zyklus dort steht aus.
  • A test client that may be installed, uninstalled and inventoried.Ein Testclient, der installiert, deinstalliert und inventarisiert werden darf.
  • A DIP share following APL\\Vendor\\App\\Version\\Arch\\10_SOURCE — existing structures are adopted, not rebuilt.Ein DIP-Share nach dem Muster APL\\Hersteller\\App\\Version\\Arch\\10_SOURCE — bestehende Strukturen werden übernommen, nicht umgebaut.
  • A Windows server for the engine (scheduled run), a network drive for packagers.Windows-Server für die Engine (geplanter Lauf), Netzlaufwerk für Packager.
  • Before a change of the baramundi version: install Build 91 and let it run at least one cycle, otherwise the change is not detected.Vor einem Wechsel der baramundi-Version: Build 91 installieren und mindestens einen Zyklus laufen lassen, sonst wird der Wechsel nicht erkannt.

Manual by designHandarbeit, bewusst

  • The software detection rule in the bMC — bConnect does not allow creating it. Hammer waits for it and shows that.Die Software-Erkennungsregel in der bMC — bConnect erlaubt kein Anlegen. Hammer wartet darauf und zeigt es an.
  • The test client after a cycle: reinstall, inventory once.Der Testclient nach einem Zyklus: neu installieren, einmal inventarisieren.
  • If you roll out through a universal dynamic group: its automatic job assignment — bConnect can neither read nor write it. Set once per app in the bMC; Hammer keeps the static group it points at up to date.Wer über eine universelle dynamische Gruppe ausrollt: deren automatische Jobzuweisung — bConnect kann sie weder lesen noch schreiben. Einmal pro App in der bMC einrichten; Hammer hält die statische Gruppe aktuell, auf die sie zeigt.
  • Apps that cannot run in the test network (agents with environment-specific dependencies) are kept as disabled.Apps, die im Testnetz nicht laufen können (Agenten mit umgebungsspezifischen Abhängigkeiten), werden als deaktiviert geführt.
  • Decisions in the readiness overview: rules source, layout of the distribution point, PSADT. Until they are taken the engine only reads.Entscheidungen in der Readiness-Übersicht: Regelquelle, Layout des Verteilpunkts, PSADT. Bis sie getroffen sind, liest die Engine nur.
  • Approvals: productive versions are changed only after an approval per version; there is no collective approval.Freigaben: Produktive Versionen werden nur nach einer Freigabe pro Version geändert; eine Sammelfreigabe gibt es nicht.
  • An existing definition that breaks a check rule is corrected by a person in the editor; the rules prevent the mistake only when a definition is created.Eine bestehende Definition, die eine Prüfregel verletzt, korrigiert ein Mensch im Editor; die Regeln verhindern den Fehler nur beim Anlegen.

Not finished yetNoch nicht fertig

  • Under 2026 R2: changing default values and value lists of variable definitions, and “moving” a variable definition — a test plan exists, the tests have not been run.Unter 2026 R2: das Ändern von Standardwerten und Wertelisten von Variablendefinitionen und der «Umzug» einer Variablendefinition — ein Testplan liegt vor, die Tests sind nicht gefahren.
  • Moving further areas to bConnect 2.0 (variables, job instances and test status): a package of its own, open. Sign-in to bConnect 2.0 with an API key on 2026 R2 is not confirmed live yet.Wechsel weiterer Bereiche auf bConnect 2.0 (Variablen, Job-Instanzen und Teststatus): eigenes Paket, offen. Die Anmeldung an bConnect 2.0 per API-Key ist auf 2026 R2 noch nicht live bestätigt.
  • A change of the baramundi version is only detected when the build ran at least one cycle before it; changes made in the console between the last cycle before and the first cycle after the change are not seen by the comparison.Ein Wechsel der baramundi-Version wird nur erkannt, wenn der Build vorher mindestens einen Zyklus gelaufen ist; Änderungen in der Konsole zwischen dem letzten Zyklus davor und dem ersten danach sieht der Vergleich nicht.
  • Conversion to PSADT: script installers are only reported, not converted.Umwandlung nach PSADT: Skript-Installer werden nur gemeldet, nicht umgewandelt.
  • The glossary preview uses the last known version of an application; when none is known it shows a marked example. The check rule for PSADT names is deliberately narrow for the list of programs to close.Die Vorschau im Glossar nutzt die zuletzt bekannte Version einer Anwendung; ist keine bekannt, zeigt sie ein gekennzeichnetes Beispiel. Die Prüfregel für PSADT-Namen ist bei der Liste der zu schliessenden Programme bewusst eng.
  • Load test with several hundred applications and a long-running test are pending; serial bConnect calls are today's bottleneck (group sync, job status).Lasttest mit mehreren hundert Anwendungen und Langzeittest stehen aus; heute sind serielle bConnect-Aufrufe der Engpass (Gruppen-Sync, Job-Status).
  • Rollout in waves: planned for the next generation, Bellows.Rollout in Wellen: geplant für die nächste Generation, Bellows.
  • Vendor APIs with login: tested against a simulated vendor, not yet against CrowdStrike itself.Hersteller-APIs mit Anmeldung: gegen einen nachgebauten Hersteller getestet, noch nicht gegen CrowdStrike selbst.
  • Update mode “uninstall, then install” for packages that cannot upgrade in place: specified, not built.Update-Modus „deinstallieren, dann installieren“ für Pakete, die sich nicht drüber installieren lassen: spezifiziert, nicht gebaut.
  • WinGet as a version source: manifests with a direct MSI/EXE work; ZIP manifests with a nested installer do not yet, and the version sort of manifest folders is being corrected (found 6 Sep with RealVNC).WinGet als Versionsquelle: Manifeste mit direktem MSI/EXE funktionieren; ZIP-Manifeste mit verschachteltem Installer noch nicht, und die Versionssortierung der Manifest-Ordner wird korrigiert (am 6.9. mit RealVNC gefunden).
  • Documentation and F1 help of the UI are generated from the field reference.Dokumentation und F1-Hilfe der Oberfläche werden aus der Feldreferenz erzeugt.
